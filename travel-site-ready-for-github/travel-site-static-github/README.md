# ลานพัทยา — GitHub Pages

## วิธีใช้
1. อัปโหลด `index.html` และ `README.md` ไปยัง Repository
2. ไปที่ Settings → Pages
3. เลือก Deploy from a branch → main → /(root)
4. กด Save

## เว็บบอร์ด
กระทู้ถูกเก็บด้วย localStorage ในเบราว์เซอร์แต่ละเครื่อง จึงไม่แชร์ข้อมูลระหว่างผู้ใช้ หากต้องการเว็บบอร์ดส่วนกลางต้องเชื่อมฐานข้อมูล เช่น Firebase หรือ Supabase

## หมายเหตุ
หน้าเว็บโหลด React และ Babel จาก CDN จึงต้องมีอินเทอร์เน็ตขณะเปิดเว็บ
