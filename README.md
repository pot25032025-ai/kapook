# ลานพัทยา 🏖️

เว็บท่องเที่ยว + เว็บบอร์ด สร้างด้วย React คอมโพเนนต์เดียว (`travel-site.jsx`)

## ฟีเจอร์

- **บทความท่องเที่ยว 4 เรื่อง** พร้อมรูปประกอบ (ทะเลหมอกภาคเหนือ, ทะเลใต้, โร้ดทริปเลียบทะเล, ทุ่งหญ้าบนดอย)
- **เว็บบอร์ด** ตั้งกระทู้ ตอบกระทู้ แยกหมวดหมู่ และกรองตามหมวดได้
- รูปภาพทั้งหมดฝังในไฟล์เป็น base64 ไม่ต้องพึ่งไฟล์ภายนอก
- รองรับมือถือ (responsive) และการตั้งค่าลดการเคลื่อนไหว (reduced motion)

## วิธีนำไปใช้งาน

ไฟล์นี้เป็น React component (ไม่ใช่หน้าเว็บสำเร็จรูป) ต้องรันในโปรเจกต์ React เช่น

```bash
npm create vite@latest lan-pattaya -- --template react
cd lan-pattaya
```

จากนั้นคัดลอก `travel-site.jsx` ไปไว้ที่ `src/` แล้วแก้ `src/App.jsx` ให้เรียกใช้:

```jsx
import TravelSite from "./travel-site";

export default function App() {
  return <TravelSite />;
}
```

แล้วรัน:

```bash
npm install
npm run dev
```

## ⚠️ ข้อควรทราบเรื่องระบบบันทึกกระทู้

โค้ดนี้เดิมสร้างเพื่อรันเป็น Artifact ใน Claude.ai ซึ่งมี API พิเศษชื่อ `window.storage`
สำหรับบันทึกกระทู้แบบถาวรและแชร์ระหว่างผู้ใช้

**เมื่อนำไปรันนอก Claude.ai** `window.storage` จะไม่มีอยู่ ผลคือ:

- เว็บยังเปิดใช้งานได้ปกติ ตั้งกระทู้/ตอบกระทู้ได้
- แต่กระทู้จะเก็บไว้ในหน่วยความจำเท่านั้น รีเฟรชหน้าแล้วหาย

ถ้าต้องการให้กระทู้ถูกบันทึกจริง ให้แก้ฟังก์ชันที่เรียก `window.storage.get/set`
ไปใช้ตัวเลือกใดตัวเลือกหนึ่ง:

| ตัวเลือก | เหมาะกับ |
|---|---|
| `localStorage` | เก็บในเครื่องผู้ใช้แต่ละคน (ง่ายสุด) |
| Backend + ฐานข้อมูล (เช่น Firebase, Supabase) | บอร์ดจริงที่ทุกคนเห็นกระทู้ร่วมกัน |

## หมายเหตุเรื่องรูปภาพ

รูปประกอบบางรูปมีลายน้ำจากเว็บต้นทางติดมา หากจะเผยแพร่เว็บสู่สาธารณะ
ควรเปลี่ยนเป็นรูปที่ถ่ายเองหรือรูปที่ได้รับอนุญาตให้ใช้งาน
